## Обзор

Morning Companion — Telegram AI-компаньон, который ежедневно
поддерживает общение с пользователем, напоминает выйти на связь и
уведомляет администратора, если пользователь не ответил.

Основные возможности (реализовано):

- Диалоги через AI (OpenRouter).
- Хранение истории сообщений (SQLite + SQLAlchemy).
- Утренние напоминания по расписанию.
- Уведомление администратора о неактивных пользователях.
